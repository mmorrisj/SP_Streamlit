================================================================================
  SoftPower Analytics - Enterprise CentOS 7 Manual Deployment
  Images: mmorrisj/softpower-analytics:1.5.5 + mmorrisj/pgvector:0.8.1-pg16
================================================================================

PREREQUISITES
  - Docker installed and running (sudo systemctl start docker)
  - Both images already loaded (docker images | grep -E "softpower|pgvector")
  - A database dump file (.dump or .sql) available locally

CREDENTIALS
  Replace these values throughout the commands below:
    DBUSER=matthew50
    DBPASS=your_secure_password
    DBNAME=softpower-db


================================================================================
STEP 1: Verify images are loaded
================================================================================

    docker images | grep -E "softpower|pgvector"

  Expected output:
    mmorrisj/softpower-analytics   1.5.5        ...   ~2GB
    mmorrisj/pgvector              0.8.1-pg16   ...   ~400MB


================================================================================
STEP 2: Create the Docker network and volume
================================================================================

    docker network create softpower_net
    docker volume create softpower_pgdata


================================================================================
STEP 3: Start PostgreSQL + pgvector
================================================================================

    docker run -d \
      --name softpower_db \
      --network softpower_net \
      --restart unless-stopped \
      -e POSTGRES_USER=matthew50 \
      -e POSTGRES_PASSWORD=your_secure_password \
      -e POSTGRES_DB=softpower-db \
      -v softpower_pgdata:/var/lib/postgresql/data \
      -p 5432:5432 \
      --shm-size=1g \
      mmorrisj/pgvector:0.8.1-pg16


================================================================================
STEP 4: Wait for PostgreSQL to be ready
================================================================================

  Run this command repeatedly until it prints "accepting connections":

    docker exec softpower_db pg_isready -U matthew50 -d softpower-db

  Typically takes 10-20 seconds after starting the container.


================================================================================
STEP 5: Start the application container
================================================================================

    docker run -d \
      --name softpower_app \
      --network softpower_net \
      --restart unless-stopped \
      --add-host=host.docker.internal:host-gateway \
      -e DOCKER_ENV=true \
      -e NODE_ENV=production \
      -e DB_HOST=softpower_db \
      -e DB_PORT=5432 \
      -e POSTGRES_HOST=softpower_db \
      -e POSTGRES_PORT=5432 \
      -e POSTGRES_USER=matthew50 \
      -e POSTGRES_PASSWORD=your_secure_password \
      -e POSTGRES_DB=softpower-db \
      -e DATABASE_URL=postgresql+psycopg2://matthew50:your_secure_password@softpower_db:5432/softpower-db \
      -e API_URL=http://localhost:8000 \
      -e TRANSFORMERS_OFFLINE=1 \
      -e HF_HUB_OFFLINE=1 \
      -e HF_HOME=/app/.cache/huggingface \
      -e SENTENCE_TRANSFORMERS_HOME=/app/.cache/huggingface/hub \
      -p 8000:8000 \
      -p 8501:8501 \
      mmorrisj/softpower-analytics:1.5.5

  NOTE: API_URL is set to http://localhost:8000 (LLM proxy disabled).
  If you later run an LLM proxy on the host at port 7001, change it to:
    -e API_URL=http://host.docker.internal:7001


================================================================================
STEP 6: Verify both containers are running
================================================================================

    docker ps --filter "name=softpower"

  Both softpower_db and softpower_app should show status "Up".

  Wait 30-60 seconds for the app to fully start, then check health:

    curl http://localhost:8000/api/health

  If curl is not available, check logs instead:

    docker logs softpower_app --tail 20

  Look for lines showing uvicorn workers have started.


================================================================================
STEP 7: Restore the database from your dump file
================================================================================

  DO NOT run migrations (alembic) when restoring from a dump.
  The dump already contains the full schema.

  --- For custom format dumps (.dump, created with pg_dump -Fc): ---

    docker exec -i softpower_db pg_restore \
      -U matthew50 \
      -d softpower-db \
      --no-owner \
      --no-privileges \
      --clean --if-exists < /path/to/your-backup.dump

  --- For plain SQL dumps (.sql): ---

    docker exec -i softpower_db psql \
      -U matthew50 \
      -d softpower-db < /path/to/your-backup.sql

  NOTE: You will likely see warnings like:
    "ERROR: relation "xxx" does not exist"
  These come from --clean trying to drop tables that don't exist yet.
  This is normal and harmless.


================================================================================
STEP 8: Verify the database restore
================================================================================

  Check pgvector extension is active:

    docker exec softpower_db psql -U matthew50 -d softpower-db \
      -c "SELECT extname, extversion FROM pg_extension WHERE extname = 'vector';"

  Check document count (main data table):

    docker exec softpower_db psql -U matthew50 -d softpower-db \
      -c "SELECT COUNT(*) FROM documents;"

  List all tables:

    docker exec softpower_db psql -U matthew50 -d softpower-db -c "\dt"

  If pgvector extension is missing (unlikely):

    docker exec softpower_db psql -U matthew50 -d softpower-db \
      -c "CREATE EXTENSION IF NOT EXISTS vector;"


================================================================================
STEP 9: Restart the app (pick up restored data)
================================================================================

    docker restart softpower_app


================================================================================
STEP 10: Access the application
================================================================================

  Web App + API:      http://<hostname>:8000
  Streamlit Dashboard: http://<hostname>:8501
  API Docs (Swagger):  http://<hostname>:8000/docs
  Health Check:        http://<hostname>:8000/api/health


================================================================================
CENTOS 7: FIREWALL (if enabled)
================================================================================

    sudo firewall-cmd --permanent --add-port=8000/tcp
    sudo firewall-cmd --permanent --add-port=8501/tcp
    sudo firewall-cmd --reload


================================================================================
CENTOS 7: SELINUX (if blocking Docker)
================================================================================

    sudo setenforce 0


================================================================================
MANAGEMENT COMMANDS - QUICK REFERENCE
================================================================================

  View app logs:
    docker logs -f softpower_app

  View database logs:
    docker logs -f softpower_db

  Stop everything (data is preserved in the volume):
    docker stop softpower_app softpower_db

  Start again after a stop:
    docker start softpower_db
    # Wait a few seconds for DB to be ready, then:
    docker start softpower_app

  Create a backup:
    docker exec softpower_db pg_dump -U matthew50 -d softpower-db -Fc > backup-$(date +%Y%m%d).dump

  Run alembic migrations (ONLY for fresh installs, NOT after dump restore):
    docker exec softpower_app alembic upgrade head

  Full teardown (preserves data volume):
    docker stop softpower_app softpower_db
    docker rm softpower_app softpower_db

  Nuclear teardown (DELETES ALL DATA):
    docker stop softpower_app softpower_db
    docker rm softpower_app softpower_db
    docker volume rm softpower_pgdata
